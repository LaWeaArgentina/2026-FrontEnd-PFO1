# 2026-C2 FrontEnd - PFO1

Landing personal desarrollada como parte de la PFO1 de la materia Desarrollo de Sistemas Web (Front End).

---

## 🚀 Resumen del proyecto

Esta landing presenta mi perfil profesional de manera clara y responsiva. Está construida con HTML semántico y CSS propio, sin frameworks externos.

El sitio incluye:
- Sección de presentación con nombre y apellido.
- Habilidades y experiencia.
- Formulario de contacto con `label` para accesibilidad.
- Navegación principal y menú móvil funcional.
- Diseño responsive con transiciones y una animación de carga suave.

## 🧩 Tecnologías utilizadas

- HTML5 semántico (`header`, `nav`, `main`, `footer`)
- CSS3 propio
- Google Fonts (`Inter`, `Poppins`)
- Flexbox y Grid para el layout
- JavaScript para el menú móvil

---

## 📝 Decisiones de diseño

| Área | Elección | Razón |
|---|---|---|
| Estilo | Paleta oscura con acento rojo | Enfatiza legibilidad, contraste y profesionalidad |
| Contenido visual | Sin imágenes personales | Minimiza prejuicios y mantiene foco en el contenido técnico |
| Estructura | Sistema de tarjetas | Claridad visual y mejor lectura rápida |
| Alternativa considerada | Línea de tiempo | Propuesta válida, descartada por simplicidad y claridad |
